# Icons-Dark

The Rawaj icons for **dark backgrounds** (`surface` #121316 or `surface-raised` #1C1E23): sand lines (#F4EFE6) with the orange element in the dark-theme `brand` (#FF7A2E). Same names, grid and rules as **Icons**; use these files in slides, social posts and design tools on dark grounds. On the website use the theme-aware `assets/Icons/rawaj-icons.json` instead.
