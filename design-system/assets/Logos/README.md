# Logos

The Rawaj logo: the word **Rawaj** whose j carries the brand idea, its dot in Rawaj orange with two smaller orange dots rising up to it, a small chart going up.

- `rawaj-logo.svg` — main logo, ink (#16181D) letters, for light backgrounds.
- `rawaj-logo-on-dark.svg` — sand (#F4EFE6) letters, dots in dark-theme orange (#FF7A2E), for dark backgrounds.
- `rawaj-logo-arabic.svg`, `rawaj-logo-arabic-on-dark.svg` — the Arabic wordmark رواج, its ج dot round and orange in its correct place.
- `rawaj-app-icon.svg` — the j mark on ink, 28px corners on a 128 grid: app icon, browser tab, social avatar.
- `rawaj-app-icon-light.svg` — the same mark on sand.
- `rawaj-mark.svg` — the j mark alone, ink on transparent: favicon on light pages.

The letters are outlined from Readex Pro (Bold), so the files render the same everywhere without fonts. Three dots, always orange, always rising to the upper right. Below 24px use the app icon.
