# Icons

The Rawaj icon set for **light backgrounds**: 25 icons on a 24×24 grid, 2px rounded stroke, drawn in `ink` (#16181D) with one orange `brand` element (#F26B1D): the Rawaj dot, a quarter disc or an accent stroke, echoing the mark.

The same icons for dark backgrounds are in **Icons-Dark**. For the website, do not use these files: inline the theme-aware markup from `rawaj-icons.json` (in this folder) and add its `css` once. Its classes `rj-i` (ink line), `rj-a` (brand line) and `rj-f` (brand fill) read the `ink` and `brand` tokens, so the icons switch by themselves when the page changes to `data-theme="dark"`.

**Services**: `web` مواقع · `mobile-app` تطبيقات · `code` برمجة مخصصة · `ads` إعلانات ممولة · `social-media` إدارة سوشيال · `seo` تحسين الظهور · `branding` هوية بصرية · `ecommerce` متاجر · `analytics` تقارير · `maintenance` صيانة وحماية · `ui-ux` تصميم واجهات
**Process**: `strategy` الخطة · `launch` الإطلاق · `growth` النمو
**Contact**: `phone` · `mail` · `location` · `chat` (for WhatsApp links; the WhatsApp logo belongs to Meta) · `calendar` (book a call)
**Interface** (ink only): `arrow-left` · `arrow-right` · `check` · `menu` · `close` · `plus`

Sizes: 24px default, 20px in buttons, 28–40px in service cards. On an orange button, both colours become `ink-on-brand`; on a teal button, both become `surface`. In Arabic pages "next" is `arrow-left`.
The orange element is decorative (2.9:1 on sand); the ink lines carry the meaning, so an icon still reads if the orange is not seen.
