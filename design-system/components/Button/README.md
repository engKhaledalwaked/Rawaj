# Button

Four buttons, all built from tokens so they work in both themes.

- **Primary**: `brand` fill with `ink-on-brand` text. One per screen: the main action (احجز مكالمة، اطلب عرض سعر).
- **Secondary**: ink outline on the surface.
- **Tech**: `accent` fill for software actions.
- **Link**: `brand-strong` text, underlined.

Text is a verb. Radius `radius-md`. Focus ring in `accent`. Never white text on orange.
