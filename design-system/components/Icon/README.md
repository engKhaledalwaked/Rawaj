# Icon

The Rawaj icon set: 25 two-colour outline icons that switch with the light and dark themes.

Each icon is ink lines plus one orange brand element (the Rawaj dot, a quarter disc or an accent stroke), echoing the mark. For a website, inline the SVG markup from `assets/Icons/rawaj-icons.json` and add its `css` string once: the classes `rj-i`, `rj-a` and `rj-f` read the `ink` and `brand` tokens, so the icons change automatically when the page switches to `data-theme="dark"`.

For tools that need a file (Figma, slides, social posts), use `assets/Icons/` on light backgrounds and `assets/Icons-Dark/` on dark ones.

Sizes: 24px default, 20px in buttons, 28–40px in service cards. Interface icons (arrows, check, menu, close, plus) are ink only. In Arabic pages "next" is `arrow-left`.
